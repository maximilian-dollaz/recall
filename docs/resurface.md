# Resurface: taking my own advice

Max's end state, in his words (30 Oct 2026):

> This is mostly a tool for me to be able to impress the thoughts that I had in my highest states of consciousness upon myself all the time.

> The key. Taking my own advice.

## What it must do

1. **Memoket syncs instantly.** New recordings land in the library already sorted.
2. **Google Docs become referenceable.** Ideas, past life directions, inspiration, thoughts, revelations. Typing "future visions" into Recall returns every matching passage in date order, with the exact lines highlighted so one glance is enough.
3. **Otter meetings (100+, past few years) get sorted** so the insights can be recalled.
4. **Highest-inspiration moments come back as phone notifications.**
5. **Past patterns and learnings resurface** so he acts on his own advice.
6. **For the past:** a mechanism finds the moments of inspiration automatically. **Going forward:** he tags new ones with "resurface" and the system brings them back.

## The unit: a spark

A spark is one passage, not a whole document. It holds Max's exact words (never paraphrased), the date he wrote or said them, where they came from, and a kind:

- **vision** (the future he sees)
- **principle** (how I should operate in the world)
- **revelation** (a truth that landed)
- **lesson** (a pattern noticed more than once)

Every spark links back to its full source, so tapping it opens the moment in context.

## The hinge

Dates. Imported Google Docs currently carry their import date (24 Oct 2026), not the date they were written. Date order depends on recovering the real dates: Drive's created and modified times, plus dates written inside docs (for example, one tab per day). Fixed before the timeline is built.
